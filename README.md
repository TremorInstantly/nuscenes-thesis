# Physics-Guided Interaction Sparsification for Efficient Ego Trajectory Prediction

## Project Overview

This repository contains the implementation of my MSc thesis.

The objective is to develop an efficient interaction-aware trajectory prediction model using the NuScenes dataset.

The project will be developed incrementally, beginning with preprocessing, followed by model development, evaluation, benchmarking, and robustness analysis.

## Planned Repository Structure

- configs/
- data/
- preprocessing/
- models/
- training/
- outputs/
- visualizations/
- docs/
